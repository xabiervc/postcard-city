# Roadmap

## Phase 0 — Preimplementation
- Approve product brief.
- Freeze vertical slice scope.
- Define domain contracts.
- Define simulation invariants.
- Create content schemas.
- Choose prototype technology after technical spikes.
- Establish testing and review workflow.

## Phase 1 — Simulation prototype
- Monthly deterministic tick.
- Region state.
- Housing, tourism, employment, transport, healthcare, budget.
- One proposal and decision resolution.
- State inspection and replay.

## Phase 2 — Vertical slice
- Small visual region.
- Executive and detailed UI.
- Media and opposition reaction.
- Election.
- Complete evaluation.
- Accessibility baseline.
- English and Spanish text pipeline.

## Phase 3 — Systems expansion
- Procedural scenario generation.
- Industry opportunities.
- More projects and crises.
- Deeper political actors.
- Scalable complexity.
- Save migration and content tooling.

## Phase 4 — Production
- Multiple regional templates.
- Campaign scenarios.
- Sandbox.
- Art, audio, animation, and narrative content.
- Additional languages.
- Extensive playtesting and balance.

## Phase 5 — Polish
- Performance.
- Accessibility audit.
- Localization QA.
- UX refinement.
- Stability.
- Onboarding.
- Final quality review.

## Scope rule
Do not start Phase 3 until the Phase 2 slice proves that the core decision loop is compelling and understandable.
